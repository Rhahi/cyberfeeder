# Cyberfeeder Privacy Policy

Cyberfeeder does not collect, transmit, sell, or share user data.

The extension stores style choices, script choices, and custom CSS locally in the browser. Users can export these settings to a file or import a previously exported file. Cyberfeeder processes page content locally to provide its interface improvements; it does not collect or transmit that content. If a user explicitly chooses to inject Cyberfeeder into another Jinteki-compatible site, the browser asks for permission to access that site's origin.

Cyberfeeder fetches card data from the Jinteki-compatible site currently being used. It does not use analytics, advertising, tracking, or remote executable code.

Questions and privacy concerns can be reported at <https://github.com/Rhahi/cyberfeeder/issues>.
